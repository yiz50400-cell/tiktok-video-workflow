# 当前商品采集

每次以当前任务商品、市场、数量为准。历史样片仅说明技术验证范围，不能成为当前商品选择或素材默认值。

用户允许任选测试商品时，选择一个新商品，保存明确品牌、系列及来源证据。新商品采集测试需要当前实际查询与下载记录；历史缓存复用不算新采集。

先调用 workflow.py capabilities，核对当前可用搜索工具。模型没有搜索或浏览器工具时明确缺项，不扫描开发项目寻找旧素材代替搜索。当前下载器支持已提供的 TikTok 视频 URL，入口 scripts/collect_videos.py --help；搜索尚未接通。

发现候选后核验同商品、商品操作、来源、下载哈希和可解码预览；同类商品仅作结构参考。指标缺失写 unknown，不把旧互动量写成当前热度。新商品商用许可单独核验。
