## 按需求选择素材路线

客户说明商品、市场、数量、成片要求，并可提供素材、参考或文案。Codex先判断素材是否足够；客户本次要求优先于长期偏好和项目默认。

| 场景 | 执行路线 |
| --- | --- |
| 客户素材齐备 | 素材检查 → 分析与方案 → 必要的稿件确认/本地化 → 剪辑、声音与字幕包装 → 导出复核 → 本机交付 |
| 客户素材需要补充且允许采集 | 素材检查 → 明确缺失镜头/参考 → 定向补充 → 合并分析并按创意混剪 → 制作与交付 |
| 客户没有素材 | 商品与需求核对 → 采集筛选 → 分析与方案 → 制作与交付 |

只用自带素材的要求直接执行。素材不足时说明具体缺口；参考作品与成片素材的用途分别记录。是否配音、是否混剪和包装组合由需求与确认方案决定。

本地视频导入、可选collection及单源/多源输入已存在于CLI/API和主链路。Codex承担需求判断与语义创作；本轮调整的是执行说明与规则，没有新增自动ETA或客户配置功能。

本轮复跑现有专项测试test_source_analysis_runs_once_and_waits_for_codex_observations通过：本地视频导入后，无collection配置可直接分析，并复用已有分析结果。这是临时合成视频的入口回归测试，验证到等待画面观察，不代替客户真实素材的全程成片验收。旧任务停用采集可显式提交collection:{}；已核对输入保存与执行分支。
