# 商品任务到本机交付的完整链路

商品、市场和本次请求数量决定任务，数量使用现有入口支持的1–100整数。每条内容具有独立稿件、镜头、包装、声音参数和版本；容量不足时保留缺料项，失败与已完成项分别展示。

Codex 负责公共来源发现、参考选择、画面语义、中文稿及内部本地化，确定性工具负责下载、分析、证据校验、声音轮换、制作和交付。现有搜索/ASR/OCR缺项保留真实状态，工具不能自行捏造语义或签署人工批准。只有明确的中文确认证据绑定准确制作稿，且内部复核通过后，才能生成音频和渲染。

主任务增加 pipeline 状态和统一恢复入口。采集、分析、创作分别复用已有模块；单条制作增加按已批准 creative.production 配置的通用准备路径，保留已有样例恢复入口。每条使用独立阶段记录；同任务排他锁防止重复执行，成功阶段哈希校验后复用，失败只重试自身。声音在并发制作前按序号从对应市场批准池预留，重试锁定选择。

本机交付包含MP4、SRT、中文口播、中文说明与证据清单，所有副本绑定来源哈希。技术QA、内部视觉/声音审核和用户最终认可分别记录。平台操作由员工自行完成。

验收覆盖不同数量、不同句数、故障后恢复、损坏产物拒绝、跨任务/市场不匹配、取消任务、同批音色轮换、审批前不调用制作，以及真实FFmpeg制作和交付。合成测试仅验证程序行为，真实样片沿用其既有质量状态。
