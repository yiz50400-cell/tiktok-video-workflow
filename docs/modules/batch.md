# 多市场批量入口

支持任务市场 MX（墨西哥）、BR（巴西）、ID（印尼）、PH（菲律宾）。员工在 Codex 直接说明商品、市场、数量和风格，Codex 提取参数并执行项目 CLI 或 MCP。

例如用户本次指定巴西市场制作7条，对应：

```sh
.venv/bin/python scripts/workflow.py create --title '商品 · 巴西批次' \
  --product '用户指定商品' --market BR --count 7 --style '达人演示'
```

数量使用本次指定的1–100整数，按目标数量生成待创作条目；创建时已规划创意和成片均为0。前三条默认作为代表样片候选，具体稿件、配音和样片按各自真实执行记录推进。

市场语音语言：MX es-MX、BR pt-BR、ID id-ID。PH 可用 `--voiceover-locale fil-PH`、`en-PH` 或 `taglish-PH`，未指定时保留待选。目标语言对采集和创作提供参数，自动当地平台搜索、语言生成及声音适配仍需对应阶段执行。货币字段只表示币种，不自动产生价格、促销或购买入口。

待选语言之后用 `set-language <job_id> en-PH` 选择，MCP 对应 `workflow_select_language`，API 对应 `POST /api/jobs/{job_id}/language`。选择语言不需要重新创建批次；已有创意保留，当地稿件与口播仍需按所选语言审阅。

## 登记真实创意

Codex 依据可见商品证据写创意，以 `plan-batch <job_id> <concepts.json>` 登记；MCP 等价工具是 `workflow_plan_batch`，API 是 `POST /api/jobs/{job_id}/batch/concepts`。

```json
{
  "concepts": [
    {
      "ordinal": 1,
      "angle": "点涂后的晕染过程",
      "hook": "点上去颜色这么明显，先看它怎么被晕开。",
      "buyer_concern": "想看点涂后实际晕开的过程",
      "proof_requirement": "同一人物连续点涂到刷具晕染，需要核准镜头边界",
      "cta_direction": "确认实际商品卡和色号后，引导查看商品",
      "source_asset_ids": []
    }
  ]
}
```

该示例提交三条不同创意时，已规划创意变为3/7；成片仍为0/7，其余四条保留待规划。本计数是创意登记数，不代表具体镜头计划、口播、素材、授权、语言审核或成片已完成。创意所述证明动作是素材需求，未引用素材时尤其不构成已证实商品效果。

条目保留每次真实修改的版本和哈希；相同内容重试不新增版本。修改重置待用户审阅，不沿用旧批准。序号越界、同次重复序号、错误市场语言、非本任务素材、已取消任务被拒绝。文本去空格/标点/大小写/全半角后相同的钩子、顾虑、证明需求和 CTA 组合不能换个角度标签凑数；近义重复仍需 Codex 创作审查，代码未声称能理解所有语义重复。

## 制作与恢复

每条已审创意交给具体镜头与稿件计划，核对商品/SKU、素材容量、七天禁复用和商业使用许可。目标数量与素材容量分别评估；素材不足保存缺料项。中文稿由用户确认，当地逐字稿内部本地化和独立复核；保持原意时免展示外语全文。真实音频超出已批准窗口时停止并给出中文调整方案，不擅自加速或延长镜头。

代表样片确认只确认相应样片及风格范围，其余稿件可批量审阅但未经审阅不得自动继承批准。主任务制作、音色轮换、本机素材预约、成片计数和交付使用 [完整链路](pipeline.md) 的 `pipeline-inputs`、`pipeline-evidence`、`run` 入口。多人共享服务待实现，发布由员工完成。
