## 固定要求

- 已通过的采集样例、采集方向和 LaMa 自然度直接继承。用户明确要求不再从头重复同一轮采集/去水印效果验收；前两开发会话只补可复用调用、状态记录及必要技术回归。后续新素材或影响画面效果的算法/参数变化另行展示，不重新让用户选择已定方案。
- 员工平台是 Codex，直接展示素材、稿件、MP4 和 SRT；当前工作流开发不新增网页工作台。
- 完整目标是采集 → 下载/准备 → 分析 → 创作确认 → 配音/剪辑 → 成片验收 → 发布；分段实施，每阶段展示真实效果。
- 默认业务入口是商品、市场、数量。Codex 负责主动采集、选取高表现结构参考、分析原话/节奏、按真实素材和时长改编口播；各阶段传递同一任务的参考与证据。员工指定参考、提供素材/文案、指定风格/时长为可选补充。自动搜索及转录是整体工作流待接通项，由主会话协调完成。
- 多员工使用是目标；当前仅本机底座，不能把负责人字段、SQLite 或本地 token 当作团队认证完成。
- 优先 TikTok 同款、高表现的商品商业带货视频，有钩子、演示/证明及推广或购买意图；同类视频用于研究广告结构。官方付费广告仅作补充，付费状态不是入选条件。可见互动不能证明销量或爆火原因。
- 先取得干净原片，失败且有带水印视频时用本地 LaMa。用户已接受 Eli 原片 3–9 秒的 6 秒 LaMa 修补效果；不是其他引擎、整个视频或任意素材已验收。后续修补保留原片并展示对比。
- 当前调用 Codex 做编排、理解、检查；确定性媒体操作本地执行。收费 API、上传商业服务及外部发布在需要时单独配置和确认。
- 复用 mexico-tiktok-product-editor 创作规则：先可用镜头和时间计划，再中文稿/独立审计；中文稿批准后本地化，最终逐字口播批准后配音/渲染。批准后可见或可听内容变更重新确认。默认干净 MP4 和独立 SRT，七天禁复用规则。
