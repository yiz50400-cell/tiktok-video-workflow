# Windows 引擎与中转接入：实施与验证

## 当前阶段

Windows 引擎适配源码、隔离中转联调入口及实机检查入口已实现。当前执行平台是 Mac arm64；Windows Job Object、Windows 文件锁和启动批处理尚未实机验收。自定义界面、内置环境安装 EXE、更新/卸载及多人使用仍在后续交付阶段。

本阶段没有生成新的商品批次、没有新增文案/音色批准、没有操作发布账号，也没有改变个人中转配置。

## 实施内容

- 跨平台锁统一接入任务、修补、制作目录和音色批次；POSIX 使用 flock，Windows 使用 msvcrt 单字节排他锁。
- 音色预约、译稿绑定修订及阶段状态改为关闭临时文件后原子发布；失败保留旧文件，新选择不覆盖既有选择。
- Windows 在启动业务进程前创建并加入 kill-on-close Job Object；超时结束 supervisor 后清理整个后代进程树；正常退出亦结束遗留后代。源码入口依赖真实 Python，未来 EXE 应调用发行包内 Python。
- POSIX 超时保留独立进程组并清理忽略 TERM/关闭管道的后代；制作阶段沿用外层组，避免嵌套新会话逃逸。
- 业务文本明确 UTF-8，子进程输出按 UTF-8 解码。Windows 启动/检查入口设置 UTF-8 并支持中文空格目录。
- 新制作默认 libx264；显式历史编码器保留，Windows 遇到 Mac 编码器明确拒绝。字体保持准确文件哈希绑定，缺失历史字体时要求建立新制作配置；已有批准文件未替换。
- 制作依赖完整检查 edge_tts、numpy、PIL 和 imageio_ffmpeg；缺失时选择已准备的离线 uv 制作环境。新增 Windows 运行程序查找、源码启动及 MCP 示例。
- 中转只读取已选 provider；临时 CODEX_HOME 不含真实 Key，Key 经环境变量传入，临时目录退出时移除。报告只记录白名单状态/用量/耗时，不保存中转原始输出。

## 真实中转联调

使用现有 `custom` provider、`https://foropencode.com/v1`、Responses、`gpt-6-sol`，Codex CLI 0.152.0，低推理强度。凭据来源为 provider token；没有要求 ChatGPT 登录。

| 实测 | 结果 | 耗时 | 用量 |
|---|---|---:|---|
| Codex 返回指定短回答 | 通过 | 13.898 秒 | 输入 8526，输出 8 tokens |
| Codex 本地工具读取隔离目录测试文件 | 通过；有实际工具完成事件 | 16.688 秒 | 输入 17194（缓存 8448），输出 60 tokens |

两次实测验证的是 Codex 经当前中转运行及一次本地工具调用。它们不能证明所有桌面插件/浏览器自动化可直接继承，也不能推定每种中转或员工配置均通过。后续 UI 应锁定运行程序版本并验证 stdio app-server 协议和审批处理。

## 本机引擎诊断

真实检查跨进程锁竞争与释放、UTF-8 子进程、超时清理、字体哈希包装、libx264 编码/完整解码以及中文空格路径/字幕，均通过。

诊断用 1 秒 180×320 的合成素材，渲染约 0.045 秒。该数据仅证明本机诊断可执行，不代表 1080×1920 正式视频、联网配音或批量产能。

`--require-windows` 在此 Mac 返回 **退出码 2**；这是平台门禁未满足，不能写成 Windows 已通过。

## 员工最终交付形式及门禁

目标交付：Windows 安装程序 `Setup.exe`，安装后桌面入口启动自定义 Codex 界面。包内携带固定 Python、FFmpeg、Codex 和工作流；老板将安装包与中文使用说明交给同事，每位员工首次填写自己的中转地址、模型和 Key，并选择工作目录。Key 在员工本机安全保存，不打进安装包。

仍需完成：

1. 干净 Windows 11 执行 `scripts/check_windows.bat`，检查 Job Object、NTFS 文件锁、中文路径和完整回归；真实正式视频执行同等质量检查。可选 LaMa/模型/GPU 单独验收。
2. 实现自定义界面、Codex stdio app-server 接入、任务进度/中文审核/失败恢复和员工本机凭据保存。
3. 内置依赖、制作 Windows 安装 EXE，测试干净机器安装、更新、恢复、卸载和员工配置隔离。
4. 用用户实际指定的批量数量压测，记录成功率、总耗时、限流/重试/重复执行和恢复成本，再确定速度与稳定性指标。

已实现的防重复、证据复用和失败恢复减少重复工作；中转限流/网络、素材完整度、配音服务及硬件仍影响实际速度。本阶段没有作生产稳定性或固定速度保证。
