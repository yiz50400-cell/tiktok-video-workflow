# 03 分镜与广告结构开发

先读 ../开发会话分工.md、../采集规则-TikTok商品广告.md，按需读取已安装 mexico-tiktok-product-editor skill。遵守文件归属；本步到分析与镜头建议，不进入新脚本配音或成片渲染。

目标：对真实商品带货视频产生可核对的分镜/动作/广告结构证据。先实现本地分析模块和 CLI，Codex 用原生画面/音频能力进行语义理解；不要为这一步偷偷接入收费 LLM API，也不要在独立后台脚本里假装拥有 Codex 对话模型。

实现 workflow/analysis/ 与 scripts/analyze_video.py：元数据、镜头候选边界、联系图/取帧、可播放时间区间、分析 JSON/报告。区分场景切换和商品动作，完整操作可以跨场景或无需切换。ASR/OCR 如本机可合理部署则用适配器实现；未取得就明确状态，禁止编造口播/字幕。写入语义观察可以通过独立结构化分析输入/保存接口，由 Codex 检视真实画面后提供，有明确来源时间。

用已下载的 Eli 干净预览以及 Isra 的既有素材观察并生成至少一份具体结构分析：开场钩子、痛点/认知冲突、上脸动作、效果证明、节奏、CTA（无则写无）、哪些区间可用/有风险。把镜头和文字中可见事实、对高互动原因的假设、未知销量分开。不要宣称已证明因果爆火；色号/产品身份需有依据。

输出 analysis-dev；不依赖采集会话完成，不改其他模块。验证时间区间合法、输出取帧来源可追溯、无 ASR/OCR 不伪造完成、原片保留。完成后写 docs/modules/analysis.md，在开发会话展示联系图/区间与实际分析，并提出共享业务接入建议。后续文案方案另行验收。
